| 能力 | 现状 | v2 |

| 一个 DSH、两个执行环境 | 远程工作区里 fs/bash/rg 走 SSH，本地不变 | 保留 |
| 多机器 + 多工作区 | connections.json + 工作区 stub 目录 | 保留 |
| 密钥/密码认证 | ssh2 + DSH 凭据库 | 保留 |

## 2. 市场调研（DSH 插件市场，28 个 SSH 相关条目）

| 插件 | 热度 | 路线 | 值得借鉴 |
|---|---|---|---|
| `dsh-remote` | 226★ / 30k 下载 | 隧道/反代 | 解决"远程 Web 服务本地访问"，不是工作区方案 |
| `@rjfan/dsh-presence` | 1248 下载 | 透明工作区 | 一条常驻连接 + 通道池；会话作用域（本地/远程显式）；@ 补全远端文件；端口转发自动恢复；可恢复删除；后台任务持久化 |
| `@goodandready/dsh-remote-workspace` | 857 下载 | 透明工作区 | 连接池、原子写、三向同步、跳板/ProxyCommand、延迟+OS 探测、设置卡片、按环境/标签分组、中央"远程"区域（主机/终端/文件/容器/隧道） |
| `dsh-remote-development` | 7★ | 透明工作区 | 强调"不额外加模型工具、不加 UI 插件"，只做透明路由 |
| `dsh-remote-panel-ssh` | 561 下载 | 远端 DSH | `sidebar.panellist` + `main` 区域嵌入式远程界面 |
| `dsh-ssh-workspace` / `dsh-remote-workspaces` / `dsh-ssh-8` | 1–2★ | 透明工作区/运维面板 | SFTP 文件管理、远程指标、终端侧栏 |

**三种路线**：A 工具型（ssh_exec/put/get，无 UI）；B 透明工作区型（我们这一类）；C 远端 DSH 实例型（多窗口/内嵌）。

**共同做法 → 我们采用**：
- 一条连接复用 + 通道池，避免每条命令重新握手（我们目前 bash 每次 exec 都新开通道，v2 要修）。
- 连接前/后显示**延迟 + 远端 OS + shell**，给用户确定感。
- `~/.ssh/config` 导入（别名、端口、用户、密钥、跳板）——最省事的入口。
- 工作区浏览器要有**面包屑 + 可编辑路径 + 筛选 + 键盘操作**。
- 端口转发：远程起的服务在本地 `127.0.0.1` 就能开，且重连后自动恢复。
- 每台机器一个**视觉身份**（颜色），贯穿胶囊、会话行、头部、控制台。

**我们的差异点**：不加模型工具、不镜像、不装远端组件；把"控制台 + 标识"做扎实，让单窗口远程开发像本地一样可读。

## 3. 信息架构（三层）

```
① 侧栏底部胶囊       常驻：连接状态 / 当前机器 / 延迟，点开快切面板
② 主区「远程」控制台  机器清单 + 概览 + 工作区 + 文件 + 终端 + 端口 + 日志
③ 会话内标识         头部胶囊 / 侧栏行徽标 / 悬停卡 / 输入框工作区
```

不替换 DSH 任何现有区域，全部通过插槽追加（见第 7 节）。

## 4. 六个界面（对应 01–06 效果图）

### 01 快速面板（侧栏胶囊点开）
- 顶部：`远程开发` + `1 台已连接 · 4 个工作区`。
- 机器切换：横向卡片（颜色 + 名称 + 已连接/未连接 + 延迟），末位 `+ 添加机器`。
- 最近工作区：名称、POSIX 路径、会话数、最近使用；当前打开的有 `已打开` 标记。
- 快捷操作：新建工作区 / 远程终端 / 端口转发 / 控制台。
- 底部：机器 + 系统 + 延迟 + host 版本（用于判断是否需要重启 DSH）。

### 02 会话与工作区标识
1. **会话头胶囊**：`● dev-box · demo-app ⌄`，状态点 + 主机 + 工作区；点击进控制台。
2. **侧栏会话行徽标**：16px 圆角方块，按机器配色 + 终端图标；本地会话保持原状态点。
3. **悬停卡**：机器名、连接状态 + 延迟、POSIX 路径、消息数/时间。
4. **输入框上方工作区**：`dev-box · /srv/demo-app`，可点击切换。
5. **工作区标题约定**：`机器名 · 项目名`，与远程目录一一对应。

### 03 远程控制台 · 概览
- 左栏：已连接 / 未连接 / `从 SSH 配置导入`，每台显示用户@IP、状态点、延迟、系统图标。
- 主机头：名称、状态、`user@host:port`、认证方式、系统版本；操作：终端 / 端口转发 / 重连 / 断开。
- 指标：工作区数、会话数、运行中的转发、往返延迟。
- 工作区卡片：路径、会话数、最近使用、`打开`；空位是"从远程目录新建"。
- 最近会话、端口转发列表。
- 右下 toast：连接结果反馈。

### 04 新建远程工作区
- 面包屑路径（可编辑、回车跳转）+ 上级 + 刷新 + 筛选 + 仅目录。
- 表格：名称 / 修改时间 / 类型，选中高亮，双击直接添加。
- 右侧预览：机器+延迟、侧栏显示名（预填 `dev-box · feature-queue`）、远程路径、两个开关（写入 AGENTS.md、创建后打开新会话）、添加按钮。
- 同面板下方：已有工作区列表 + 🗑（二次确认"确认移除"，明确写出"只摘除侧栏，不删机器目录"）。

### 05 添加机器
- 左：`~/.ssh/config` 导入——路径、重新扫描、勾选列表（alias、user@host:port、密钥、需代理标记）、`导入选中 N 台`。
- 右：手动配置——名称/主机、端口/用户/认证方式（密钥|密码分段）、私钥路径（浏览 + 已检测密钥提示）、口令、高级折叠（跳板机/代理命令/指纹）、启动时自动连接 / 记住密码、`测试连接`（成功后显示 Linux/发行版/延迟/shell）、保存并连接。

### 06 终端与端口转发
- Tab：概览 / 工作区 / 文件 / 终端 / 端口转发 / 日志。
- 终端：独立 SSH PTY 会话，标签 `dev-box — bash`，可多开；右侧连接信息（shell、系统、cwd、延迟）。
- 端口：自动检测新监听端口并转发（绿色提示条 + 一键打开）、转发列表（本地→远程、来源、打开/复制/停止）、新增转发（远程端口 → 本地自动分配）。

## 7. 与 DSH 插槽的映射（可行性已核对）

| 界面 | 插槽 | 说明 |
|---|---|---|
| 胶囊 + 快切面板 | `sidebar.footer.action` | 现有入口不变 |
| 「远程」控制台入口 | `sidebar.panellist` + `main`（key `remote`） | 侧栏图标打开主区页面 |
| 会话行徽标 | `sidebar.session.row.leading` | 提供 `sessionId`，可查所属工作区；本地会话不渲染 |
| 行悬停补充 | `sidebar.session.row.hover` | 追加远程信息行 |
| 会话头胶囊 | `conversation.session.header.utilities` | 提供 `sessionId` |
| 默认设置 | `settings.section` 或 `plugins.row.config` | 自动连接、标识开关等 |

Host 侧在现有 `/state`、`/connections`、`/dirs`、`/workspaces` 基础上增加：`/test`（延迟/OS）、`/ssh-config`（解析）、`/forwards`、`/terminal`（PTY 通道）、`/metrics`。连接层改为**每台机器一条 SSH 连接 + 按需通道**。

## 8. 风险

- 依赖 DSH 内部插槽与 `ctx.fs` / `ctx.tools` / `ctx.subprocess` 补丁：DSH 升级需跟进（保留版本探测与降级提示）。
- 终端与端口转发需要 host 进程内长期资源，断开/退出要清理干净。
- 深色主题需要逐一覆盖 token，浅色先行。
